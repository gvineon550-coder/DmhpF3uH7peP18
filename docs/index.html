📖 О сайте · как пользоваться

Что это такое?

Личный дашборд-помощник. Живёт на GitHub Pages, обновляется автоматически каждый час. Показывает погоду, новости, космос, курсы — и хранит твои заметки, привычки, задачи.

Как пользоваться?
  • 🎯 Привычки — добавляй и отмечай каждый день
  • ✅ Задачи — пиши что надо сделать
  • 📝 Заметки — сохраняются сами
  • 🍅 Помодоро — 25 мин работа, 5 отдых
  • 💧 Вода — отмечай выпитые стаканы
  • 😊 Настроение — 1 клик в день
  • 💤 Мой сон — вводи лёг/встал, смотри график
  • ⏳ Счётчики дат — «до отпуска N дней»
  • 💾 Бэкап — сохрани все данные в JSON
🔒 Приватность — что важно знать

Все твои данные хранятся только в браузере (localStorage). Никто — ни автор сайта, ни GitHub — не видит твои заметки, привычки, задачи.

Важно: если очистишь кэш Chrome — данные пропадут. Сделай бэкап!
